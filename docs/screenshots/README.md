# Screenshots

The main README embeds the files below. Drop the PNGs in here with exactly these
names and they will show up — no README edit needed.

| File | What to capture |
| ---- | --------------- |
| `editor.png` | The SQL editor with a query run and the results grid filled — the hero shot, so pick a query with a few interesting columns. |
| `schema.png` | The schema tree expanded on the left with the structure panel of a table open. |
| `wiki.png` | A wiki page for a table, ideally one generated from the schema. |
| `er.png` | The ER diagram with several related tables in view. |

Guidelines:

- Use the app's dark theme so all four shots match.
- Window at roughly 1400×900, then export at 2× for a sharp result on retina
  displays — GitHub scales them down.
- Use a demo database, not a real one. Check the visible table and column names,
  the connection name and the query history for anything you would not want
  published.
- Keep each file under ~500 KB so cloning the repository stays cheap.
